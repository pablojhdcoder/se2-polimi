\section{Use of Generative AI Tools}
\label{sec:ai_tools}%
Generative AI was used as a support tool during the preparation of this ATD, in a similar way to other software (editors, LaTeX, version control). It did not produce the document autonomously; the authors used it for specific tasks such as structuring acceptance test coverage, interpreting test results, and refining the wording of sections.

\subsection{Tools Used}
\begin{itemize}
    \item General-purpose large-language model assistants (e.g.\ ChatGPT, Claude, Cursor) for text drafting, clarification of technical concepts, and suggestions on structure and phrasing.
\end{itemize}

\subsection{Example Prompts}
The following types of prompts are representative of how AI was used:
\begin{itemize}
    \item \textbf{Identifying test cases:} ``Given the RASD/DD requirements [R1--R42] and use cases, suggest a set of acceptance test cases that cover registration, login, trip recording, path creation, and reporting, with clear pass/fail criteria.''
    \item \textbf{Understanding test outcomes:} ``In the Jest output, several tests are marked as \texttt{skipped}. What are the usual reasons Jest skips tests (e.g.\ \texttt{describe.skip}, \texttt{it.todo}, conditional skip), and how can I tell from the log why a specific test was skipped?''
    \item \textbf{Improving wording:} ``This paragraph is too long and repeats ideas. Suggest a shorter, clearer version that keeps the same technical meaning: [excerpt].''
\end{itemize}

\noindent\textit{Note:} Other queries were used (e.g.\ LaTeX formatting, explaining error messages); the ones above illustrate the main use cases. All AI-generated text was reviewed and edited by the authors before inclusion.

\subsection{Verification and Refinement}
All outputs were checked as follows:
\begin{itemize}
    \item \textbf{Accuracy:} Suggestions were compared with the RASD, DD, ITD, and with the actual test runs and installation steps performed.
    \item \textbf{Consistency:} Wording and structure were aligned with the rest of the document and with the course deliverables' style.
    \item \textbf{Responsibility:} The authors take full responsibility for the content of this ATD. Generative AI was used only as an aid; every claim, test outcome, and recommendation was verified and approved by the authors.
\end{itemize}

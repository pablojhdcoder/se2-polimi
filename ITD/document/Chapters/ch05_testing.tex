\section{Testing Procedure}
\label{sec:testing_procedure}

The testing verification process follows the pyramid strategy described in the Design Document (DD), ensuring that individual components are verified in isolation before validating their interactions and complete user journeys.

\subsection{Testing Levels}
\begin{itemize}
    \item \textbf{Unit Tests:} Validate business logic in isolation using mocks for all dependencies.
    \item \textbf{Integration Tests:} Verify interactions between layers (Service $\to$ Repository $\to$ DB) and between services.
    \item \textbf{End-to-End Tests:} Validate full user flows from the mobile client to the database.
\end{itemize}
